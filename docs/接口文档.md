# 当前 HTTP 接口

更新：2026-10-28。字段、约束与错误响应以 [OpenAPI 快照](../contracts/openapi.json) 为准；运行服务提供 `/v3/api-docs`。除注册、登录、演示和健康检查外，业务接口要求 `Authorization: Bearer <token>`。

## 面试启动

`POST /api/interviews/sessions` 支持本人 `resumeId` 或摘要。岗位来源二选一：`targetJobId + targetJobRevision`，或 `targetRole + jobDescription`。

```json
{
  "targetRole": "Java 后端工程师",
  "resumeId": 7,
  "jobDescription": "负责订单接口，熟悉 Java、MySQL 和 Redis。",
  "difficulty": "ADVANCED",
  "mode": "GENERAL",
  "totalRounds": 6
}
```

`difficulty` 可为 BEGINNER/STANDARD/ADVANCED，缺省 STANDARD；`jobDescription` 最多 20,000 字，岗位名称最多 160 字。会话响应和重新读取都带难度；回答不能更改本场难度。已保存目标岗位的名称以服务端快照为准；归属、修订号、来源互斥和非法难度在启动前校验。

专项训练增加 `trainingTopic: DATABASE | CONCURRENCY | PERFORMANCE | PROJECT`，`totalRounds` 必须为 3～6，可省略材料。复练使用 `retrySessionId + retryRound`（本人已完成会话中有评估的真实轮次），总轮数同样为 3～6；不可混入主题或新材料，实际岗位、材料及难度均沿用原场。响应中的 `agent.training.retry` 保存服务端读取的原能力、问题、回答、证据和缺口。`GET /api/interviews/sessions/{sessionId}/retries` 按本人归属分页返回从该场发起的复练记录（默认 page=1、size=20）。

公共岗位、匹配、收藏、诊断评分、职业报告、投递、模板、独立求职准备任务及项目诊断练习接口已退役，详见 [退役清单](../contracts/interview-focus-retirements.json)。
