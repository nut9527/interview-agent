# 后端模块边界

更新：2026-10-26。当前业务模块只有 auth、resume、jobs、interview、ai；application 负责编排账号与演示空间的跨模块生命周期。

- 跨模块只访问 `api` 类型，仓储、Entity、Mapper 与具体 Service 为内部实现。
- 简历管理与面试都定义各自的 AI 能力；业务 Prompt 和结构校验留在所属模块，通用模型连接位于 ai。
- interview 通过 `ResumeSnapshotReader`、`TargetJobSnapshotReader` 读取本人材料，不访问其他模块数据库。
- jobs 仅有私有目标岗位。`TargetJobRules` 为确定性要求拆分与原文定位规则。
- `InterviewTransitions` 与 `InterviewAgentPolicy` 只依赖面试数据和确定性 JDK 类型。
- application 通过 `ResumeUserData`、`JobUserData`、`InterviewUserData` 清理活动数据，身份删除处理历史数据兼容。

`ModuleBoundaryTest` 检查全部生产模块、公开 API、无环依赖、Controller 分层和规则纯度；`ArchitectureRulesTest` 编译反例验证门禁。历史 Flyway 迁移放在独立 `db.migration` 包，不构成活动业务模块。
