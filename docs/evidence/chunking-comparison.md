# 分块调整对照

本轮用同一批 25 份资料、91 道题和两份分块实现重新测量。当前分块器将同一标题下的相邻正文、列表、代码合并，识别 Markdown 代码围栏并过滤纯图片。可检索的证据块由旧实现的 1,880 个降至 467 个。原文偏移随分块保存，历史版本保留原块。[冻结的旧实现](../../backend/src/test/resources/rag-corpus/baseline/KnowledgeText.java) · [当前实现](../../backend/src/main/java/cn/edu/whu/zhizhida/knowledge/domain/KnowledgeText.java)

下表按 80 道有答案题计算。命中要求返回块包含完整标注引文，各题等权。其余 11 道资料不足题在报告中单列。全库是内存实验，产品选择资料仍有 5 份上限。

| 范围 | 检索方式 | 旧分块 Recall@6 | 当前分块 Recall@6 |
| --- | --- | ---: | ---: |
| 每题选定资料 | 词项 | 85.63% | 90.63% |
| 每题选定资料 | 词项与 BGE 融合 | 80.63% | 90.00% |
| 全部资料 | 词项 | 78.13% | 89.38% |
| 全部资料 | 词项与 BGE 融合 | 75.63% | 85.63% |

融合实验固定两路各 30 个候选，使用 RRF（k=60）和每章节优先 2 块的规则，再取 Top-6。报告保存每种范围的逐题排名、三次计时、标注和源码指纹。[本轮分块对照报告](reference-chunking.json)

在项目根目录运行以下命令可生成独立的复测报告。旧版和新版各用同一组 Java 诊断断言检查引文和排名。相关单测运行 95 项，其中 93 项通过、2 项按配置跳过，两版真实 BGE 对照各通过 1 项。

```text
node scripts/evaluate-reference-retrieval.mjs --chunking
```
