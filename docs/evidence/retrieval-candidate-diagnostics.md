# Top-30 诊断与全库检索实验

原范围已有明确排序失败：**22 题**至少一段标注引文进入 RRF Top-30，却未进入最终 Top-6；全库为 **23 题**。全库增加了主题混杂度，但引文 Recall@6 从 **80.00% 降至 75.00%**。这些样本可用于后续 reranker 对照。

[完整逐题结果、分块正文及源码指纹](reference-retrieval-diagnostics.json)

## 实验条件

- 同一批 27 份真实资料、103 题：90 道正例、13 道资料不足题，开发 51 题、验证 52 题；本轮未修改问题或 gold。
- `selected` 使用每题原有的 4–5 份资料；`all27` 检索全部 27 份资料。两组使用同一份生产分块和 BGE 向量索引。
- BGE-small-zh-v1.5-q，512 维，向量最低分 0.55；词项和向量各取 30，RRF K=60，最终取 6，同章节配额 2。
- 全库适配器仅用于内存实验。原范围的 103 次向量检索均与生产适配器逐项一致；应用接口仍保留最多 5 份资料的限制。

本轮测量候选和排序，未接入 cross-encoder，也未测回答生成。查询向量在两组间复用，因此不将本次耗时作为性能数据。

## 命中与排序

Recall 按 90 道正例取宏平均。章节命中要求文档、标题一致；引文命中进一步要求单个块包含完整标注引文。

| 指标 | 原范围 | 全库 |
| --- | --- | --- |
| 章节 Recall@3，最终结果 | 81.11% | 76.67% |
| 章节 Recall@6，最终结果 | 89.44% | 87.78% |
| 章节 Recall@30，RRF | 98.89% | 98.33% |
| 引文 Recall@3，最终结果 | 72.22% | 64.44% |
| 引文 Recall@6，最终结果 | 80.00% | 75.00% |
| 引文 Recall@30，RRF | 98.89% | 95.00% |
| 有引文在 RRF Top-30、未进最终 Top-6 的题数 | 22 | 23 |
| 首个引文命中排在最终第 4–6 位的题数 | 7 | 9 |

全库 RRF Top-30 的理想重排 Recall@6 上界为 **95.00%**，比当前高 20 个百分点；原范围上界为 98.89%，高 18.89 个百分点。这是假设已知 gold 时的上界，实际 reranker 收益尚未测量。

章节口径会掩盖“返回了同章其他段落”的情况。引文口径用于定位标注证据，也可能漏计未标注的等价证据；本轮未重新穷举这些证据。

按引文口径，全库有 6 题缺少至少一段 RRF Top-30 证据：

```sh
node scripts/evaluate-reference-retrieval.mjs --diagnostics
```

脚本使用项目离线依赖和独立 BGE 进程，生成带运行编号的 JSON，结束后清理本轮构建目录及模型进程。报告保留两路 Top-30、RRF Top-30、最终 Top-6、gold 各阶段排名、候选并集和全文分块字典，并按分区、题型汇总。

后端 11 项测试、语料与文档 21 项检查通过，0 失败、0 跳过。两次诊断运行的 103 题、两种范围、全部阶段排名一致；报告中的源码 SHA-256 与当前实现一致。
