# Agent 与中间件运行验收

历史真实模型验收使用 `interview-prompts-v5`、`interview-output-v3` 和 `phased-v1`。本轮 RocketMQ 分进程验收使用 `TOOL` 路由、`A1` 策略和 `phased-v2` 协议。

## 生成契约

模型只生成需要判断的内容。最终轮的结束动作、能力目标和追问策略由服务端填写，下一题能力 ID 从路由目标派生；领域对象与前端接口仍保留完整字段。契约压缩保留字段语义和引用约束，评价先选引文再写对应事实，不强制凑固定数量的优势、建议或长篇总结。

首次最终输出因两个未知维度仍携带引用被拒；已有的一次修复清空这些引用后通过校验并提交。持久化结果正确保留消息编号去重、数据库失败重试和本人职责，没有将局部引文扩大为整段回答的评价。

完整模型响应、逐阶段校验、调用台账和用量均有对应记录。验收脚本的一次报告查询错误发生在开场成功之后，该尝试的 2 次调用也计入统计：两次执行共 7 次生成、21,494 tokens。失败尝试与成功结果分别保存。
