# 使用指南

职智达支持岗位面试、专项训练、题库练习和资料自测，训练结果可归入个人计划与学习目标。

注册并登录个人账号后，可保存求职材料和练习记录。登录后默认进入「模拟面试」。体验功能时，在登录页选择「进入独立演示空间」，使用示例岗位和简历开始练习。每次演示登录创建独立空间，默认有效期为 4 小时。

## 演示空间

没有准备材料时，先在登录页选择「进入独立演示空间」。演示空间自带岗位和简历，默认使用 Mock 模型，适合先走通完整流程。

1. 在「求职材料 → 目标岗位」打开 **Java 后端校招生｜订单与库存**，点击「查看要求与简历证据」，选择 **周宁（演示）**。
2. 岗位要求提到 MySQL 乐观锁，简历的「校园商城订单服务」写到在事务内通过版本号更新库存。对照两段原文，可以先想：两个请求同时扣减最后一件商品时，服务如何判断哪次更新成功？
3. 回到岗位详情，点击「使用这份简历与岗位开始面试」，选择教学练习、标准难度和 3 轮。
4. 结束后打开「查看能力复盘」，按下文「根据反馈复练」继续。

## 准备岗位和简历

1. 在「求职材料 → 目标岗位」点击「添加目标岗位」，填写岗位名称，粘贴招聘说明（JD）。点击「从 JD 提取要求」，对照原文核对要求和检索词，然后保存。
2. 在「求职材料 → 简历」新建简历，或上传文字型 PDF、DOC、DOCX。文件最大 5 MB，PDF 最多 30 页，扫描件需先转成可复制的文字。DeepSeek 模式将提取的正文（包括联系方式）发送给模型，识别姓名、岗位、教育和项目等字段；默认 Mock 模式使用本地规则。检查导入预览中的个人信息与项目经历，点击「确认并保存导入」。
3. 需要润色时，在简历编辑页点击「AI 优化简历」。对照当前草稿和建议，勾选要采用的修改，核对后保存。要比较修改前后的项目经历，保存后打开「版本历史」，点击「版本对比」，再勾选两个版本。
4. 回到岗位卡片，点击「查看要求与简历证据」，选择简历。逐条查看与岗位要求关联的经历，再点击「使用这份简历与岗位开始面试」。

单次岗位练习可直接在「模拟面试」中选择「本场自定义 JD」，填写岗位名称和招聘说明。

## 完成模拟面试

在「岗位 JD 面试」中选择练习方向、难度和轮数。练习方向包括综合能力、项目深挖和后端基础，练习长度支持 3、6、9、12 轮。「教学练习」在每轮回答后给出反馈与追问提示，「正式模拟」在整场结束后统一展示反馈。

点击「开始模拟面试」，阅读问题并提交回答。开启「整场计时」后，离开页面继续计时，到时提醒并允许继续作答。中途离开后，从「历史面试记录」点击「继续面试」恢复练习。

## 根据反馈复练

在已完成的面试中点击「查看能力复盘」，选一张有评估结果的卡片，对照回答原文查看遗漏的细节。

- **立即复练。** 点击「复练此能力」重新作答。精选题练习的对应按钮是「复练这道题」。复练后，在「前后对照」中比较两次回答。
- **留到下次。** 在同一张卡片点击「加入训练计划」。从左侧「学习记录 → 个人训练计划」找到任务，点击「开始练习」。下次回到同一处，点击「继续练习」即可接着作答。

[查看训练计划界面](evidence/interview-plan-mobile.png)

跨题训练时，打开「学习记录 → 训练目标」，填写目标名称，选择同一能力的 2–3 道不同题目，核对完成标准后点击「建立目标」。在目标卡片点击「提出训练草稿」，核对练习顺序和验收备注，确认后按任务练习。

练完后点击「核对跨场证据」。目标进度采用已完成的 DeepSeek 训练，并要求同一轮回答的有效引用支持目标要求的各个维度。有效场景数达到标准后，逐场核对原回答，填写复核记录，勾选确认项，再点击「确认训练目标完成」。Mock 模式用于演练创建目标、确认计划和执行训练的操作流程。

要了解一条学习观察来自哪次回答，打开「学习记录 → 学习观察」，在记录中展开引用或点击「查看来源会话」。发现表述有误时，可点击「纠正观察」。页面上的「允许使用学习观察」开关默认关闭。开启后，可在目标卡片手动选择同一能力的有效 DeepSeek 观察，再提出训练草稿。

## 用题库和笔记补练

- **练精选题。** 在「题目与资料 → 精选题目」按主题、难度或关键词找题，打开题目后点击「练习这道题」。想连练几道题时，进入「抽题练习组」，选择题数和每题轮数，点击「生成练习组」。每道题有独立的面试记录。
- **用笔记出题。** 在「题目与资料 → 资料与出题」粘贴笔记，或上传文字型 PDF、DOCX、UTF-8 编码的 TXT 或 Markdown 文件。核对正文并入库后，勾选资料，点击「从所选资料生成题目」。逐题核对题干、参考要点和引用原文，点击「确认并保存到我的题目」后即可自测。
- **向笔记提问。** 在「资料与出题」展开「更多工具：资料问答与分类」，选择资料，输入问题并点击「检索并回答」。可以对照引用核实答案，沿用原资料继续追问，或在「问答历史」中找回这次问答。
- **带着笔记模拟面试。** 在「模拟面试」选择「专项训练」，选定主题，可添加最多 5 份资料，在「练习长度」选择 3–6 轮后点击「开始专项训练」。也可以直接从资料原文点击「使用这份资料进入专项训练」。

精选题库共 64 题。外部参考题在页底标注出处，可点击「查看来源」阅读原文；点击「查看解析」后，「延伸阅读」会按本题主题检索相关文档。

在「资料与出题」点击「参考资料」，可按主题或标题筛选 27 份原文：JavaGuide 15 篇、小林 coding 8 个章节、《Spring 实战》第 5 版 4 个章节。点击「查看原文」，核对后「确认入库为 v1」，即可用于问答、出题或专项训练。配套测试问题见 [RAG 测试集](../backend/src/test/resources/rag-corpus/README.md)。

资料上传支持 PDF 最大 100 MB、1000 页，DOCX 最大 30 MB，TXT / Markdown 最大 400 KB。系统解析文字内容，单份资料正文上限为 200 万字符；扫描图片需先转换为文字。面试开始时固定所选资料版本，复盘引用对应本场使用的原文。

部署、模型配置与运行维护见[启动与故障排查](启动与故障排查.md)，系统实现见[架构与代码入口](architecture.md)。
