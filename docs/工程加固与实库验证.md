# 工程验证与数据隔离

更新：2026-10-26。本文说明当前账号、简历、私有目标岗位及面试流程的验证方式；运行入口见 [README](../README.md)。

## 分层验证

| 层次 | 入口 | 验证范围 |
| --- | --- | --- |
| 后端单元/Web | `backend/` 执行 `mvn test` | 规则、业务编排、MockMvc、架构边界、真实 OpenAPI 导出；不要求业务数据库 |
| 隔离 MySQL 与覆盖率 | 根目录 `node scripts/verify-backend.mjs --offline` | Surefire、Failsafe 实库和 JaCoCo 合并门禁；行与分支覆盖率均至少 80% |
| 前端 | `frontend/` 执行 pnpm typecheck/lint/test/build/contract:check | 类型、静态检查、请求/会话/草稿与 AI 审阅、构建和 DTO 契约 |
| 浏览器 | `frontend/scripts/verify-interview-browser.mjs` | 生产构建中的难度/JD、材料选择、历史重开、简历预览/打印、导航和移动端；使用合成 API |

具体运行结果按日期保存于 `docs/evidence/`。历史记录中的已退役功能和测试数量不作为当前项目能力声明。架构规则及契约验证见 [核心规则与接口契约](核心规则与接口契约.md)。

## 隔离 MySQL 的生命周期

[verify-backend.mjs](../scripts/verify-backend.mjs) 不读取私密 `.env`，不复用已有数据库，不操作 Docker 守护进程：

1. 检查 PATH 中 mysqld、mysql、mysqladmin、Maven 及独立端口；默认 13307 被占用即失败，不按端口终止已有服务。
2. 在项目 `.runtime/integration/mysql-*` 创建独占数据与临时目录，启动只监听 127.0.0.1 的 MySQL。
3. 生成随机临时密码，通过标准输入及子进程环境创建测试账号；凭据不放进命令行或报告。
4. 使用 `IT_DATABASE_*` 指向 `zhizhida_test`，过滤继承环境中的 Spring 数据源、Flyway、配置和 Profile 覆盖。
5. 执行 `mvn verify`，记录于 `backend/target/verification.log`；Maven 单次上限五分钟。
6. 最终关闭本次 MySQL，核对目录归属后只删除本次创建的数据。已有 MySQL、Java、Node 和业务数据不属于清理目标。

独立 `application-it.yml` 不导入开发者私密配置，启用 Flyway 校验、禁止 clean，并使用 Mock AI。测试数据库守卫只接受 `zhizhida_test` 或 `zhizhida_test_<小写字母数字>`，拒绝单独的 Flyway 连接。不要将业务数据放入这些名称的库，也不要给测试账号其他库权限。

已有专用测试库时，可显式设置 IT_DATABASE_URL/USERNAME/PASSWORD 并在 backend 执行 `mvn verify`。生产数据库不能用于测试。

## 关键不变量

- **账号与演示空间**：注册账号与会话同事务；演示容量检查、简历复制和会话创建保持原子性；注销或回收失败时整体回滚。
- **简历**：正文、revision 和版本快照同事务；过期修订不能覆盖当前内容。解析接口只返回待核对字段，确认后才创建。
- **目标岗位**：所有读写限定本人；修改/删除校验 revision，分析使用已保存材料。
- **面试**：先检查本人归属、题号和已提交命令回放，再领租约和扣额。模型在事务外执行，结果提交核对原令牌、到期时间和预期状态；失败不保存半轮问答，回放不重复调用模型。
- **共享额度**：多维额度桶按稳定顺序加锁，任一维度拒绝则全部回滚；数据库时间对齐固定窗口。窗口边界可能突发，工作单位不等于供应商账单。
- **前端**：请求与缓存按账号代次隔离，忽略迟到回包；未确认的回答保留原编号，简历保存回包不覆盖保存期间的新输入。

## 观测与边界

业务指标使用有限枚举标签，不包含账号、材料原文、Token 或请求编号。`/actuator/**` 使用独立管理鉴权；未配置 METRICS_TOKEN 时拒绝访问，普通用户 Token 不能替代监控凭据。HTTP 请求编号用于排障，不作为高基数指标标签。

数据库幂等不保证外部模型恰好调用一次；客户端取消也不保证撤回服务端写入或费用。合成 API 浏览器测试和 Mock AI 不能证明真实模型效果。既有业务库升级、生产部署、HTTPS、备份恢复、压测与告警须单独验证。

产品收敛时的已完成项与未验证项见 [2026-10-26 记录](evidence/2026-10-26-interview-focus.json)，其中附加启动器进程清理测试未通过，不能将它写成启动器全部验证成功。
